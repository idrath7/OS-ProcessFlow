# OS ProcessFlow
### 6th Semester Final Project — Operating Systems (OS)

**OS ProcessFlow** is a modern CPU Scheduling and Memory Visualization desktop application developed as a **6th Semester Final Project** for the Operating Systems course.

The application demonstrates how CPU scheduling algorithms manage process execution and how memory is allocated and released during simulation.

## Features

- Round Robin CPU Scheduling
- Non-preemptive Priority Scheduling
- Interactive Gantt Chart
- Live Process Execution Visualization
- Simulated RAM Allocation and Release
- Process State Monitoring
- Completion Time, Waiting Time, and Turnaround Time Calculation
- Light and Dark UI Themes

## Technologies Used

- **Programming Language:** Python
- **GUI Framework:** PySide6 (Qt for Python)
- **UI Styling:** Qt Style Sheets (QSS)
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub
- **Testing:** Python unittest

## How to Run

```bash
pip install -r requirements.txt
python main.py
```
